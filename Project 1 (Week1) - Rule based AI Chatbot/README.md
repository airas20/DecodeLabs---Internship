# Rule-Based AI Chatbot 🤖

## DecodeLabs - Artificial Intelligence Project 1

A simple rule-based AI chatbot developed using Python.

## Project Objective

The objective of this project is to create a chatbot that responds to predefined user inputs using control flow and decision-making logic.

## Features

- Handles greetings such as hello, hi, and hey
- Answers questions about the chatbot
- Provides a basic explanation of Artificial Intelligence
- Provides information about the project
- Uses if-elif-else logic
- Uses a continuous while loop
- Handles exit commands
- Provides a response for unknown inputs

## Technologies Used

- Python
- Visual Studio Code

## How It Works

The chatbot uses predefined rules instead of machine learning.

It takes the user's input, processes it, and checks it against predefined conditions using if-elif-else statements.

The chatbot continues interacting with the user until an exit command such as `bye`, `exit`, `quit`, or `goodbye` is entered.
