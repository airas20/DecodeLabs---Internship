# Rule-Based AI Chatbot 🤖

## Artificial Intelligence - Project 1

A simple rule-based AI chatbot developed using Python.

## Features

- Handles greetings
- Answers basic questions
- Explains Artificial Intelligence
- Uses if-elif-else logic
- Uses a continuous while loop
- Handles exit commands
- Responds to unknown inputs

## Technologies Used

- Python
- Visual Studio Code
