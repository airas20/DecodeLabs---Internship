# Rule-Based AI Chatbot 🤖

## Project 1 - Artificial Intelligence

This project is a simple rule-based AI chatbot developed using Python.

## Features

- Handles greetings
- Answers basic questions
- Provides information about Artificial Intelligence
- Uses if-elif-else decision-making
- Runs continuously using a while loop
- Handles exit commands
- Provides a default response for unknown inputs

## Technologies Used

- Python
- VS Code

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python chatbot.py
